# Homework 3 — Flight Booking

A flight-booking agent built with LangChain, LangGraph, and OpenAI.

## Setup

```bash
uv sync
uv run python main.py
```

Set `OPENROUTER_API_KEY` before running the app (for example, in PowerShell:
`$env:OPENROUTER_API_KEY = "..."`). A local `.env` file is also excluded from Git.
